# بوابة التواصل مع مندوب التعاضدية

موقع ثابت (ملف `index.html` واحد) كيتنشر بالمجان على GitHub Pages.

## ✨ شنو فيه من وسائل التواصل
- زر **واتساب** (فالأعلى + زر عائم دايما ظاهر) برسالة جاهزة
- **مكالمة هاتفية** و**SMS** و**إيميل** بضغطة وحدة، مع زر **نسخ** للرقم والإيميل
- **تيليغرام**، **فيسبوك**، **قناة/مجموعة واتساب** (كتظهر غير إلا عمرتي الروابط)
- **استمارة** بطريقتين:
  - عبر الواتساب: كتفتح محادثة فيها الرسالة منظمة بالاسم والموضوع والأولوية (بلا حاجة لأي خدمة خارجية)
  - عبر الإيميل: كتوصلك الرسالة فالإيميل
- اختيار **الموضوع** (استفسار، طلب موعد، مواكبة ملف، شكاية، اقتراح) و**الأولوية** و**وقت الرد المفضل**
- **مواعيد اللقاء** ومكانه ورابط الخريطة
- **إعلانات** تبدلها بسهولة
- **رسالة جاهزة للتوزيع** + أزرار مشاركة (واتساب، تيليغرام، فيسبوك) + **QR Code**
- زر **احفظ جهة الاتصال** (vCard) فالهاتف
- تنبيه واضح: ما تبعتوش معلومات طبية حساسة، والموقع غير رسمي

## 🚀 النشر على GitHub Pages (5 دقائق)
1. دخل لحسابك فـ GitHub وصاوب **New repository**، سميه مثلا `mandoub` وخليه **Public**.
2. اضغط **Add file → Upload files** وحط `index.html` و`README.md` (وصورتك `photo.jpg` إلا بغيتي)، ثم **Commit**.
3. دخل لـ **Settings → Pages**.
4. تحت **Branch** اختار `main` و`/ (root)` ثم **Save**.
5. من بعد دقيقة تقريبا غادي يطلعلك الرابط:
   `https://USERNAME.github.io/mandoub/`
6. حط هاد الرابط فـ `siteUrl` داخل `CONFIG` (باش يخدم QR والمشاركة بالرابط الصحيح)، ثم Commit.

## ✏️ تبديل المعلومات
كلشي كاين فبلوك `CONFIG` فبداية `index.html`. بدل غير القيم:
- `name`, `role`, `org`: الاسم والصفة
- `whatsapp`: بصيغة دولية بلا `+` ولا `0` فالبداية، مثال `212612345678`
- `phone`, `email`, `telegram`, `facebook`
- `whatsappGroup` / `whatsappChannel`: روابط المجموعة والقناة
- `announcements`: زيد أو حيد الإعلانات
- `meeting`: المكان والمواعيد
- `documents` و`faq`: عدلهم حسب الواقع

من GitHub: افتح `index.html` ثم أيقونة القلم ✏️، بدل، ثم Commit. الموقع كيتحدث فدقيقة.

## 📧 تفعيل الإرسال بالإيميل (اختياري ومجاني)
1. دخل لـ https://web3forms.com وحط الإيميل ديالك.
2. غادي توصلك **Access Key** فالإيميل.
3. حطها فـ `web3formsKey` داخل `CONFIG`.

إلا ما درتيش هاد الخطوة، زر الإيميل غادي يفتح تطبيق البريد فالهاتف بالرسالة جاهزة. والواتساب كيخدم فكلا الحالتين.

## 📣 نصائح لحملة التوزيع
- ابعث الرسالة الجاهزة فمجموعات الواتساب ديال الموظفين.
- طبع **QR Code** وعلقو فالمصالح (بعد موافقة الإدارة).
- حط الرابط فبيو الواتساب ديالك وفتوقيع الإيميل.
- جدد الإعلانات بانتظام باش يرجعو الناس للموقع.

## 🔒 الخصوصية والمسؤولية
- الموقع **ما كيحفظش** أي معطيات؛ الرسائل كتمشي للواتساب أو الإيميل ديالك فقط.
- نبه الموظفين باش ما يبعتوش معطيات صحية أو وثائق حساسة عبر الاستمارة.
- الموقع **مبادرة شخصية**، ماشي الموقع الرسمي للتعاضدية. ما تستعملش شعارها الرسمي إلا بإذن مكتوب منها.
- تأكد أن الوثائق والمساطر المكتوبة فالموقع مطابقة لما كتعتمدو التعاضدية.
